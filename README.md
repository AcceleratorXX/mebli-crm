# Меблі CRM

Локальна CRM для ведення проєктів з виготовлення меблів: питання перед конструюванням, нагадування, вхідні файли, рахунки та журнал подій.

Прорахунок з Excel (.xlsx, напр. замовлення з ViyarPRO) завантажується на вкладці «КП» кнопкою «📥 Прорахунок з Excel» або «+ з Excel» біля виробу: матеріали й фурнітура йдуть у список виробу, собівартість — у ціну з націнкою.

## Запуск

Потрібен [Node.js](https://nodejs.org/) 18+. Залежностей немає.

- Windows: двічі клацнути `start.bat`
- або: `node server.js`, потім відкрити http://localhost:3000

Дані зберігаються в папці `data/` (у git не потрапляє). Для резервної копії достатньо скопіювати цю папку.
